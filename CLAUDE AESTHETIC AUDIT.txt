You are conducting a UX, aesthetic, and functionality audit of this social media platform. 
Your focus is the FRONTEND EXPERIENCE only — not auth security, not deployment,

PHASE 4 — INTERACTIVE ELEMENT AUDIT
════════════════════════════════════════════

Go through every interactive element you can find in the codebase. 
For each one, verify it has an actual handler — not just a visual element with no action.

Find all buttons:
  grep -rn "<button\|<Button\|onClick" --include="*.tsx" --include="*.jsx" \
    | grep -v node_modules | grep -v ".test." \
    | grep -v "//.*onClick" \
    | head -100

Find all links:
  grep -rn "<Link\|href=" --include="*.tsx" --include="*.jsx" \
    | grep -v node_modules | grep -v ".test." | head -80

Find all form submissions:
  grep -rn "onSubmit\|handleSubmit\|<form" --include="*.tsx" --include="*.jsx" \
    | grep -v node_modules | head -60

For EVERY button, link, and form found, categorize it as:

  ✅ WIRED — has a real handler that does something
  ⚠️  PARTIAL — has a handler but it's a console.log, TODO, or empty function
  ❌ DEAD — onClick with no function, href="#", disabled with no explanation
  ❓ UNKNOWN — can't determine without running the app

Report the full list:

  INTERACTIVE ELEMENTS AUDIT:
  [Component file] — [element description] — [STATUS]

Then give counts:
  Total buttons/CTAs found: N
  ✅ Wired: N
  ⚠️  Partial: N
  ❌ Dead: N
